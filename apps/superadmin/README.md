# Super Admin console (legacy)

React/Vite console for platform-level governance (tenants, subscriptions, billing). It was written against the retired Node API, which has been removed (see git tag `legacy-snapshot`), so it has **no working backend** and still contains demo data and hard-coded values.

It is kept only until it is rebuilt on the Spring Boot API (`services/api`) as a platform-admin area. Do not deploy it to production as-is.
